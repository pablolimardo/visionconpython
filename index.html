Preparar el laboratorio

Objetivo: dejar el Arduino y la carpeta del proyecto listos.

1) Cargar Firmata. En el Arduino IDE: Archivo → Ejemplos → Firmata → StandardFirmata y subirlo a la placa.

Firmata convierte al Arduino en un robot obediente: no tiene programa propio, solo espera órdenes por el cable USB. Ejemplo de orden: "pin 8, prendete".

2) Anotar el puerto. En Herramientas → Puerto fíjense cuál es (por ejemplo COM3). Escríbanlo acá: ________

3) Cerrar el Arduino IDE. Si queda abierto, ocupa el puerto y Python no puede conectarse.

4) Instalar las librerías en la terminal:

pip install pyfirmata2 opencv-python mediapipe

5) Crear la carpeta del proyecto (por ejemplo gestos) y descargar adentro el modelo de manos, un archivo de unos 8 MB que ya viene entrenado:

https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task

Pegan ese link en el navegador y guardan el archivo con ese mismo nombre dentro de la carpeta.

El modelo es el cerebro ya entrenado que sabe reconocer manos. Nosotros no lo entrenamos: lo descargamos y lo usamos, como instalar la app de un juego.

6) Crear el archivo manos.py en la misma carpeta, con este contenido. Es el "traductor" entre la cámara y nuestro programa. Por ahora no hace falta entenderlo línea por línea:

# manos.py  -  Detector de manos (usa el modelo hand_landmarker.task)
import os
import time
import cv2
import mediapipe as mp
from mediapipe.tasks.python import BaseOptions, vision

RUTA_MODELO = os.path.join(os.path.dirname(os.path.abspath(__file__)),
                           "hand_landmarker.task")

_detector = vision.HandLandmarker.create_from_options(vision.HandLandmarkerOptions(
    base_options=BaseOptions(model_asset_path=RUTA_MODELO),
    running_mode=vision.RunningMode.VIDEO,
    num_hands=1,
    min_hand_detection_confidence=0.7,
    min_tracking_confidence=0.6))

_CONEXIONES = [(c.start, c.end) for c in vision.HandLandmarksConnections.HAND_CONNECTIONS]
_inicio = time.time()
_ultimo_ms = -1

def detectar(frame):
    """Recibe una imagen de la cámara (BGR).
    Devuelve la lista de 21 puntos de la mano (cada uno con .x e .y entre 0 y 1),
    o None si no hay ninguna mano."""
    global _ultimo_ms
    ms = int((time.time() - _inicio) * 1000)
    if ms <= _ultimo_ms:                 # el tiempo tiene que crecer siempre
        ms = _ultimo_ms + 1
    _ultimo_ms = ms
    imagen = mp.Image(image_format=mp.ImageFormat.SRGB,
                      data=cv2.cvtColor(frame, cv2.COLOR_BGR2RGB))
    resultado = _detector.detect_for_video(imagen, ms)
    if resultado.hand_landmarks:
        return resultado.hand_landmarks[0]
    return None

def dibujar(frame, puntos):
    """Dibuja el esqueleto de la mano sobre la imagen."""
    alto, ancho = frame.shape[:2]
    def pt(i):
        return int(puntos[i].x * ancho), int(puntos[i].y * alto)
    for a, b in _CONEXIONES:
        cv2.line(frame, pt(a), pt(b), (255, 255, 255), 2)
    for i in range(len(puntos)):
        cv2.circle(frame, pt(i), 4, (0, 0, 255), -1)
Todos los programas de la clase (prueba.py, etc.) se guardan en la misma carpeta que manos.py y hand_landmarker.task. Si no, Python no los encuentra.

MISIÓN 1

Armar el circuito

Objetivo: conectar los 3 LEDs a los pines 8, 9 y 10.

LEDPin del ArduinoCamino
RojoD8Pin → resistencia → pata larga del LED.
Pata corta → GND.
Los tres LEDs comparten el GND.
AzulD9
AmarilloD10
Cada LED es una calle de un solo sentido: la corriente entra por la pata larga y sale por la corta. La resistencia es el semáforo que evita que pase demasiada corriente y se queme el LED.
Nunca conecten un LED sin su resistencia. Con la placa desconectada del USB, armen todo y recién después enchufen.
✅ Chequeo: el copiloto le muestra el circuito al profe antes de seguir. (Después se intercambian los roles.)

MISIÓN 2

Python le habla al Arduino

Objetivo: prender los 3 LEDs, uno por uno, desde un programa de Python.

import time
from pyfirmata2 import Arduino

placa = Arduino("COM3")                  # <-- cambiar por TU puerto

pines = [8, 9, 10]
leds = [placa.get_pin(f"d:{p}:o") for p in pines]   # d = digital, o = salida

for led in leds:                         # recorre los 3 LEDs
    led.write(1)                         # 1 = prender
    time.sleep(0.5)
    led.write(0)                         # 0 = apagar

placa.exit()                             # cierra la conexión
LíneaQué hace
Arduino("COM3")Se conecta a la placa por el puerto
get_pin("d:8:o")Elige el pin: digital, número 8, output (salida)
write(1) / write(0)Prende / apaga
Mini-desafío: hagan que los LEDs vayan y vuelvan como el "Auto Fantástico", y que cada vuelta sea más rápida.
✅ Chequeo: los 3 LEDs se prenden en orden desde Python.

MISIÓN 3

Abrir los ojos: detectar la mano

Objetivo: ver la cámara y los 21 puntos de tu mano dibujados en tiempo real.

import cv2
import manos                             # nuestro archivo manos.py

cam = cv2.VideoCapture(0)                # 0 = cámara principal (probar 1 si queda negra)

while True:
    ok, frame = cam.read()               # frame = una "foto" de la cámara
    if not ok:
        break
    frame = cv2.flip(frame, 1)           # efecto espejo

    puntos = manos.detectar(frame)       # ¿hay una mano? devuelve los 21 puntos o None
    if puntos:
        manos.dibujar(frame, puntos)     # dibuja el esqueleto

    cv2.imshow("Camara (Q para salir)", frame)
    if cv2.waitKey(1) & 0xFF == ord("q"):
        break

cam.release()
cv2.destroyAllWindows()
Un video es un flipbook: fotos seguidas. Cada vuelta del while es una página nueva. Los 21 puntos son el esqueleto de un personaje de videojuego: Python no ve "una mano", ve puntos con coordenadas.
Mini-desafío: acerquen y alejen la mano, y prueben con poca luz. ¿A qué distancia deja de verla? Anótenlo.
✅ Chequeo: aparecen los puntitos sobre tu mano y la siguen cuando la movés.

MISIÓN 4

¡Hechizo! La mano controla los LEDs

Objetivo: contar los dedos y prender el LED correspondiente.

La lógica: un dedo está levantado si su punta está más arriba que su articulación del medio. En una imagen, arriba es y = 0, así que "más arriba" significa un y menor.

Este es el programa completo. Reemplazá el puerto y probalo:

import math
import cv2
import manos                             # nuestro archivo manos.py
from pyfirmata2 import Arduino

# ---------- ARDUINO ----------
placa = Arduino("COM3")                  # <-- cambiar por TU puerto
leds = {1: placa.get_pin("d:8:o"),       # 1 dedo  -> rojo
        2: placa.get_pin("d:9:o"),       # 2 dedos -> azul
        3: placa.get_pin("d:10:o")}      # 3 dedos -> amarillo

def mostrar(dedos):
    for n, led in leds.items():
        led.write(1 if n == dedos else 0)    # prende solo el LED que coincide

# ---------- CONTAR DEDOS ----------
def distancia(a, b):
    return math.hypot(a.x - b.x, a.y - b.y)

def contar_dedos(p):                     # p = lista de los 21 puntos de la mano
    # Pulgar: punta (4) vs articulación (3), medido desde la base del meñique (17)
    dedos = 1 if distancia(p[4], p[17]) > distancia(p[3], p[17]) else 0
    # Índice, mayor, anular, meñique: (punta, articulación del medio)
    for punta, medio in [(8, 6), (12, 10), (16, 14), (20, 18)]:
        if p[punta].y < p[medio].y:      # punta más arriba = dedo levantado
            dedos += 1
    return dedos

# ---------- CAMARA ----------
cam = cv2.VideoCapture(0)

try:
    while True:
        ok, frame = cam.read()
        if not ok:
            break
        frame = cv2.flip(frame, 1)

        dedos = 0                        # sin mano = 0
        puntos = manos.detectar(frame)
        if puntos:
            manos.dibujar(frame, puntos)
            dedos = contar_dedos(puntos)

        mostrar(dedos)                   # ordena al Arduino
        cv2.putText(frame, str(dedos), (30, 80), cv2.FONT_HERSHEY_SIMPLEX,
                    2.5, (0, 255, 136), 4)
        cv2.imshow("Hechizos (Q para salir)", frame)
        if cv2.waitKey(1) & 0xFF == ord("q"):
            break
finally:
    mostrar(0)                           # dejar todo apagado al salir
    cam.release()
    cv2.destroyAllWindows()
    placa.exit()
Mano con los dedos hacia arriba y a unos 40-60 cm de la cámara. Si se prenden los LEDs "de a saltos", es normal: la cámara duda entre dos gestos. Es una versión sin filtro a propósito.
✅ Chequeo: 1 dedo prende el rojo, 2 el azul, 3 el amarillo, y el puño apaga todo.

🛠️ Si algo falla

SíntomaProbá esto
Error de puertoCerrar el Arduino IDE y el Monitor Serie. Revisar el número de COM.
El LED no prendePata larga hacia la resistencia, pata corta a GND, pin correcto en el código. Probar con la Misión 2.
Ventana de cámara negraCambiar VideoCapture(0) por VideoCapture(1). Cerrar Zoom, Meet u otros programas que usen la cámara.
No detecta la manoMás luz, fondo simple, mano a 40-60 cm.
Cuenta mal los dedosDedos hacia arriba. Agregar print(dedos) para ver qué número lee.
Error al instalar mediapipeAvisar al profe: puede necesitar otra versión de Python.
No such file o error con hand_landmarker.taskEl archivo del modelo tiene que estar en la misma carpeta que manos.py y llamarse exactamente hand_landmarker.task.
No module named manosEl programa tiene que estar guardado en la misma carpeta que manos.py.
